## Changed contract and implementation

Owner selected a strict supported-local-storage default. Before any selected-path canonicalization, lookup or body read, parse own mountinfo and reject unsupported provider ancestors. Named in-kernel storage policy: ext2/3/4, btrfs, xfs, f2fs, ntfs3, exfat, vfat/msdos, tmpfs, iso9660 and udf. Unknown, network, autofs, FUSE and overlay types are rejected. This is driver admission on a trusted local storage stack, not a generic resident-bit detector. Local FUSE requires a future explicit provider contract; this release has no trust exception.

`source/engine.cpp` resolves clean absolute paths one component at a time using openat2. Each approved mount segment prohibits symlink/magic-link and unapproved mount crossing; a known approved nested mountpoint can start another segment. Actual fd statx mount ID and fstatfs magic must match the bound mount table. Ordinary approved nested local mounts are retained, not blanket skipped. The conservative policy also rejects unsupported ancestor/covered-stack records; exotic covered-mount stacks are not qualified. A mount table cannot certify a backing block device, and concurrent same-user remount/provider substitution or privileged backing-stack changes are outside this security boundary. No universal no-hydration claim is made.

Source contents are reopened only through a controlled `/proc/self/fd/<held-fd>` reference and copied/hash-checked in bounded64KiB chunks into the owned extraction snapshot. Source file size/growth and the final held-fd hash are limited to32MiB. Extractors and the embedding producer receive that owned snapshot, never a later unchecked public source path. Before commit a newly admitted held descriptor must have the original device/inode and hash. Descriptor ownership transfers only after QFile/fdopendir success. Model, producer, vector, preprocessing, page/literal/FTS association and generation/control contracts remain unchanged; producer3dd4ddd9a133e9861ec834a2434121f99872b2ac94b1b211690a620357408414 is reused.

Paths accepted by this source API are round-tripping Unicode/UTF8 strings, without NUL, dot components, redundant/trailing separators or more than4096UTF8 bytes. Every raw readdir name must round-trip byte-for-byte before any child lookup; otherwise it is skipped with a native-byte warning. Undecodable mountpoint records cannot alias a valid Unicode record. This does not claim arbitrary byte-name support. Parent owns the UI raw-file-URL guard: `%FF` information can already be lost before a QString reaches the service.

Enumeration streams readdir and checks stop/cancellation per entry. Defaults:100000 visited entries (including hidden/unsupported names),10000 admitted directories,10000 total watch paths,16MiB cumulative UTF16 path-payload accounting,10000 eligible files and64 selected roots. Private EngineOptions expose smaller finite budgets for actual integration controls; production service uses defaults. A complete bounded eligible list is sorted only after enumeration. On incomplete enumeration, unseen old rows are not deleted, scan/watch work stops, and old admissible cached content remains searchable. A canceled precommit scan preserves existing rows and watches. This is a work/path/watch bound, not a hard RSS or wall-time limit over blocking storage or every extractor/producer workload.

Startup removes rows only for definite policy rejection, a missing/link/non-directory root, or a definitively rejected nested provider path. Metadata/descriptor permission/resource/verification uncertainty instead fails initialization closed and retains the old database for recovery. Live search always applies current admission; unsupported cached paths cannot become results. Successful complete scans reconcile excluded/missing paths. No source writes, Baloo changes, model/index deletion or policy-bypassing fallback were added.

## Stable status and lifecycle semantics

Existing `error`, `ready` and `model_ready` keep their failure meaning. A scan limit/error alone leaves the engine operational/ready and the last accepted admissible index searchable; cached passages may remain old until a successful scan. It clears active scan/watches and requires a deliberate retry after reducing selection/exclusions or correcting the cause.

- `scan_error`: last failed/canceled enumeration diagnostic, cleared by a successful scan.
- `scan_entries`: visited raw names, excluding dot/dotdot; `scan_directories`: admitted/queued directories, including roots; `scan_path_bytes`: cumulative UTF16 payload accounting of visited and retained paths.
- `scan_warnings`: at most20 provider/name skip details. Provider detail has path/error; invalid-name detail has the valid parent directory, entry_bytes_hex and error, without inventing a Unicode child path.
- `scan_skipped_providers` and `scan_skipped_names`: full skip counts, including details beyond the20-record display limit.

Parent must display scan errors/warnings in UI-v4. The previously current app did not consume these fields. EngineOptions adds source-compatible trailing budget fields; both service/core objects must be rebuilt together, not ABI-mixed.
