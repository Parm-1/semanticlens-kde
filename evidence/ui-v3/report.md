## Producer and observation contract

Primary Qt evidence distinguishes the phases. [Image.asynchronous](https://doc.qt.io/qt-6/qml-qtquick-image.html#asynchronous-prop) loads a local image in another thread; [Image.status](https://doc.qt.io/qt-6/qml-qtquick-image.html#status-prop) Ready means loaded, while Loading is still in progress. Runtime Qt QML type metadata orders Null/Ready/Loading/Error as0/1/2/3 and exposes paintedWidth/paintedHeight. A backend file URL and successfully decoded local QImage are earlier observations than a loaded QML Image or its rendered scene. Painted dimensions are floating-point geometry, not exact integer pixel bounds.

[QQuickWindow.afterFrameEnd](https://doc.qt.io/qt-6/qquickwindow.html#afterFrameEnd) observes scene submission; [grabWindow](https://doc.qt.io/qt-6/qquickwindow.html#grabWindow) returns the rendered window contents, including supported readback when a single valid window is not exposed. Submission/presentation signals and rendered readback are distinct evidence. On this host the actual window is visible but unexposed: its submitted-frame counter remains1 across subsequent valid readbacks. Requiring exposure or a subsequent submission signal alone therefore produced bounded observer failures, preserved below. No compositor-presentation claim is inferred from readback.

The retained smoke now waits for the actual QML Image's Ready status, current source URL, visibility/opacity and positive item/painted geometry. It retains a scene readback after that state and takes the final capture on a subsequent observer turn, before closing the dialog. A later submitted frame is recorded if present; for the observed unexposed case, the explicit retained `QQuickWindow::grabWindow` scene readback is the frame witness. Raw exposure, submission counts, dimensions, source, status, ready/readback/capture times and pixels remain. A saved blank cannot pass the known PDF fixture's page-capture check: the painted region must contain at least10 dark-ink pixels and over90% white-paper pixels. The independent separate comparator checks actual source content, below. The original 90-second total bound and actual `closed` signal/invisibility/empty-URL/file-absence cleanup remain unchanged. A timeout or blank is failure, not relabeled success.
