# Project instructions

Read `GOAL.md` before substantial work. It is the canonical scope, acceptance and
continuation record. This thread's Codex owner carries implementation, validation,
repairs and delivery. Update the checkpoint when results or boundaries change.

Use the user's supplied working and delegation preferences. Use Luna for settled
packages, Sol/high for unknown contracts and required independent review. Keep
one writer per shared surface and preserve frozen evaluation inputs and results.

Validate the Linux embedding producer and preprocessing before treating a worker,
ranking or evaluation contract as settled. Preserve selected-root privacy, exact
identifier retrieval, model identity and UI responsiveness. Do not mutate Baloo
configuration or index the user's personal folders as an unannounced test.

Keep local model weights, indexes, private paths/data and secrets out of Git.
Prepare public artifacts locally; the repository identity and public publication
remain a user decision after a concrete candidate is available.
